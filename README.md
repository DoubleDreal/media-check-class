# 매체 사용 습관 점검·개선 프로젝트 (6학년 국어)

학생이 로그인 없이 매체 사용 습관을 기록·분석하고, 목표를 세워 실천한 뒤 결과를 공유하는 수업 도구입니다.
학생 입력은 선생님의 구글 시트에 자동으로 모이고, 학급 집계는 시트가 자동으로 계산합니다.

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 이 반에서 쓰는 학생용 도구 (GitHub Pages 배포) |
| `share/index.html` | **공유용** 학생용 도구. 수집 서버 주소(`ENDPOINT`)가 비어 있어 제출 기능이 꺼져 있습니다 |
| `teacher/수집서버.gs` | 선생님 구글 시트에 붙이는 Apps Script 수집 서버 |
| `teacher/교사용_매체사용점검_자료.xlsx` | 자동 집계 시트 (구글 시트로 열어 사용) |
| `teacher/학생용_개인분석.xlsx` | 대체용 개인 분석 시트 |
| `teacher/폼_자동생성_스크립트.gs` | (선택) 구글 폼 자동 생성 |

## 내 반에서 쓰려면 (약 20분)
1. `teacher/교사용_매체사용점검_자료.xlsx`를 내려받아 구글 드라이브에 올리고 **Google 스프레드시트로 열기**를 합니다.
2. 시트에서 **확장 프로그램 → Apps Script**를 열고 `teacher/수집서버.gs` 내용을 붙여 넣습니다.
3. 맨 위 `CLASS_CODE`를 내가 정한 수업 코드로 바꾸고 저장합니다.
4. 함수 `setupSheets`를 한 번 실행합니다(권한 승인 필요). `R_사전`, `R_일일` 등의 탭이 만들어집니다.
5. **배포 → 새 배포 → 웹 앱**: 실행 사용자 *나*, 액세스 권한 *모든 사용자*로 배포하고 웹 앱 주소(`…/exec`)를 복사합니다.
6. `share/index.html`을 내 저장소나 내 사이트에 올리고, 파일 위쪽의 `var ENDPOINT="";` 안에 복사한 주소를 붙여 넣습니다.
7. 학생에게 도구 주소, 수업 코드, 번호를 알려 줍니다.

코드를 고친 뒤에는 **배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.

## 주의
- 수집 서버 주소는 선생님의 시트로 연결됩니다. 다른 사람의 주소가 든 파일을 그대로 쓰면 학생 자료가 그 사람 시트로 갑니다. 반드시 **내** 주소를 넣으세요.
- 수업 코드는 저장소에 올리지 마세요. 학생 이름 등 개인정보 수집은 학교 방침과 보호자 동의 여부를 확인하세요.
