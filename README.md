# 매체 사용 습관 점검·개선 프로젝트 (6학년 국어)

학생이 로그인 없이 매체 사용 습관을 기록·분석하고, 목표를 세워 실천한 뒤 결과를 공유하는 수업 도구입니다.

- `index.html` — 학생용 점검 도구 (GitHub Pages로 배포). 수업 코드와 번호를 입력해 사용합니다.
- `teacher/수집서버.gs` — 교사 스프레드시트에 붙이는 Apps Script 수집 서버. `CLASS_CODE`는 자리 표시 값이므로 실제 수업 코드로 바꿔 사용하세요.
- `teacher/교사용_매체사용점검_자료.xlsx` — 자동 집계 시트 (구글 시트로 변환해 사용)
- `teacher/학생용_개인분석.xlsx` — 대체용 개인 분석 시트
- `teacher/폼_자동생성_스크립트.gs` — (선택) 구글 폼 자동 생성
